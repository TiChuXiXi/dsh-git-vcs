# dsh-git-vcs 0.2.0

## 兼容性

- 要求 Node.js ≥ 22.12.0，DSH ≥ 0.2.1-alpha.2。
- 实测 DSH 0.2.1-alpha.2；对应官方 master 提交 d743267388641bc76f17c45ce8b4c231aed1d32c。
- 旧 DSH 0.1.7 用户应保留插件 0.1.2，升级前先更新宿主。

## 改进与修复

- 合并 develop 的 DSH 新版兼容更新，完善安装、升级和排障文档。
- 加固 RPC 请求格式、端点校验和请求取消传播。
- 修复首次提交前取消暂存、通配符文件名误操作，以及符号链接和仓库根边界逃逸。
- 贮藏支持包含未跟踪文件，准确报告没有新建贮藏的情况。
- Git 凭据相关输出脱敏，补齐隔离 Git 回归与真实宿主集成测试。

## 验证

- npm test：10 组 Node 回归、64 项 host、17 项客户端、6 项 VM/JSON 检查。
- Chrome DOM 探针：33 项几何与空态交互检查。
- DSH 集成：真实认证、stage/unstage、Origin 防护、协议检查、客户端资源分发。
- Windows/Linux 桌面与全部真实菜单尚未逐项端到端验证；不支持按行提交、并排 diff 或冲突编辑器。

## 安装

npm 发布完成后执行：

```sh
dsh plugin --profile web add dsh-git-vcs@0.2.0 --registry=https://registry.npmjs.org
```

重启 dsh web 并刷新浏览器。GitHub 源码可直接通过 v0.2.0 标签安装。
